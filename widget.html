🎟️ Home-screen widget

  1. Install Scriptable (free) from the App Store.
  2. Tap Copy script below.
  3. Open Scriptable, tap +, paste, and name it Tickets. Tap ▶︎ once to preview.
  4. On the home screen, long-press → + (Edit → Add Widget) → Scriptable → pick Small, Medium or Large → Add.
  5. Long-press the new widget → Edit Widget → Script: Tickets.

Paste once. New bets load automatically on every refresh, so you never need to re-paste for new tickets. (If you pasted the older version, replace it with this one one time.)

The widget asks iOS to refresh every minute, but iOS decides the real timing, usually every 5–15 minutes. Tap the widget to open the live tracker, which updates every 30 seconds.
